# VIA_lekc_izstrade

Repo priekš "Programmatūras izstrādes un uzturēšanas dzīves cikls" kursa

## Apraksts

Konsoles programma C++ valodā, kas ievada un salīdzina F1 braucēju rezultātus.
Lietotājs ievada braucēju vārdus un punktus, programma izvada:
- visu braucēju sarakstu ar punktiem
- braucēju ar visvairāk punktiem (līderis)
- braucēju ar vismazāk punktiem (pēdējais)
- vidējo punktu skaitu
